## 📖 About the Project

NeuroFlow AI is a responsive SaaS landing page that showcases a fictional AI workflow automation platform.

The project was developed as a frontend learning exercise inspired by the design and engineering concepts presented in the **IIT Bhubaneswar Frontend Hackathon**. It focuses on writing clean React components, building responsive layouts, and creating a modern user experience.

---

## ✨ Features

* 🚀 Modern AI SaaS Landing Page
* 🎨 Clean, responsive UI
* 📱 Mobile-friendly layout
* 🧩 Component-based React architecture
* 📊 Bento-style feature cards
* 💰 Responsive pricing section
* 💬 Testimonials section
* 🎯 Semantic HTML structure

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/SanskritiParida/frontend-battle-ai-landing-page.git
```

### Navigate into the project

```bash
cd frontend-battle-ai-landing-page
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

---

## 📦 Production Build

```bash
npm run build
```
